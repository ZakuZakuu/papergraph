# v0.1.5

Released 2026-08-07.

## Included

- Improves narrow and portrait-window layout behavior for the research demo.
- Hides mobile-only operation hints so the bottom controls remain visible.
- Makes the outer demo banner and viewer iframe share the viewport without
  clipping the bottom control bar.
- Reserves mobile safe-area space for the top and bottom controls.
- Defaults a first-time narrow-screen session to a collapsed sidebar while
  preserving any explicit user choice.
- Keeps the theme default aligned with the operating system, while retaining
  explicit light/dark choices per browser.
