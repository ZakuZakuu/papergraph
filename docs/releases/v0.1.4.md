# v0.1.4

Released 2026-08-07.

## Included

- Exposes comparative evidence in Claim browsing, including declared
  comparator Results and the measurements attached to each support edge.
- Adds visible comparison connectors and preserves the Claim browser while a
  comparator Result is inspected.
- Renders compact scientific-notation values legibly without changing the
  source literal stored in the graph.
- Adds the lower-left Line guide for evidence flow, reconstructed relations,
  support edges, comparison evidence, and recorded gaps.
- Avoids continuous Canvas redraw while the viewer is idle.
- Documents the bilingual onboarding flow, viewer source-of-truth rule, and
  research-demo attribution boundary.

## Verification

- Full suite: 59 passed.
- Existing synthetic `paper-evidence-graph/0.2` fixture validates and builds
  with the release viewer.
- Wheel and zero-install `.pyz` artifacts are built by the release workflow.
- Runtime dependencies remain Python standard library only.
