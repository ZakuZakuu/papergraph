# v0.1.6

Released 2026-08-11.

## Included

- Adds an optional, graph-digest-checked `locales/zh-CN.json` display sidecar.
- Adds browser-language detection and persistent `中 | EN` switching in the
  static Viewer, with field-level English fallback.
- Keeps evidence quotes, numeric values, units, formulas, page locators, and
  graph identifiers unchanged across languages.
- Adds Compact/Full Gap tiers: core evidence gaps stay prominent while detail
  gaps are collapsed by default and can be revealed for inspection.
- Carries locale data into both served builds and self-contained standalone
  HTML output.
- Updates the extraction Skill, README files, specs, tickets, and the research
  demo to document the localization pass and Gap visibility behavior.
