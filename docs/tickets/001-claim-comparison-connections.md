# 001 - Claim Comparison Connections

**What to build:** While a reader browses a comparative Claim, show each
declared comparator as a viewer-only connector into the real focal support
edge, make that connector inspectable, and provide a compact guide to line
meanings without changing the graph artifact.

**Blocked by:** None - approved spec is present in `docs/specs/001-claim-comparison-connections.md`.

**Status:** in progress

- [ ] A Claim browse state renders comparison connectors only for declared
      comparison Results and retains the direct support edge as the sole link
      into the Claim.
- [ ] Connector selection opens the originating support relation and exposes
      its declared comparative evidence.
- [ ] Multiple comparison Results remain separately visible and selectable.
- [ ] A transient Line guide explains visible line categories.
- [ ] Automated build-product checks and a manual Transformer inspection pass.
