# Live demo assets

This directory is reserved for GitHub Pages demonstration builds. Prefer papers whose terms clearly permit redistributing the graph's embedded quotes and evidence metadata. When that is not established, keep excerpts selective, add a prominent source/use notice, link to the original publication, and obtain a rights-holder decision before treating the sample as broadly reusable.

When a paper is selected, place its standalone viewer at a stable path such as `docs/demo/<paper-slug>/index.html`, then enable GitHub Pages from `/docs` on the `main` branch. Its public URL will be:

`https://zakuzakuu.github.io/papergraph/demo/<paper-slug>/`

Do not commit private research runs or graph artifacts for papers whose redistribution terms have not been checked.
